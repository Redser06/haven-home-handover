# ADR-001: URL Deployment Options (Lovable vs Firebase Hosting)

## Decision
We chose Firebase Hosting (or potentially Lovable) as our URL deployment layer. Supabase is selected for Backend (auth, db, realtime). Firebase is only an option for Hosting if we need its static hosting capabilities, but given the Lovable option, Lovable is preferred for prototyping velocity if it supports the required Auth/Handover architecture.

## Context
We need a live URL for sharing the prototype. Both Lovable and Firebase Hosting provide static deployments. Since the requirements specify Supabase as the backend (R-A), the deployment layer just needs to host the static React SPA.
